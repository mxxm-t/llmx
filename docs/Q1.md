# Q1_0 read support

Q1_0 uses GGML type 41: a binary16 scale and 128 sign bits in 18 bytes. The CPU registry decodes it into the existing float products. Vulkan embeds and multiplies it through the shared backend owners, with block-int16 rows and eligible prompt tiles for F16/int8 on integer-dot profiles. F32, BF16 and wider fallback paths retain their precision rules. There is no Q1 quantize writer.

The native `low-bits` test covers all finite scales, packed positions, guards, embedding, dense/logits/additive, grouped and routed operations, precision policy, row classes and actual row/tile dispatches. Its Q1 two-row checks compare standalone and grouped calls and one-column and batched outputs bitwise. Python raw blocks have independent scalar and numpy decoders. The tiny dense tied/untied and MoE references are in `tests/data/baseline_q1_0.json` and `tests/data/baseline_q1_0_split.json`; their exact fixture allowances and prospective F16/BF16 calibrations are in [PRECISION](PRECISION.md).
