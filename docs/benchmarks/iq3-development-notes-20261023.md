- **Gotchas:** IQ3_S and Q3_K have the same block byte count but different layouts. The 512-entry dictionary is format data, not an algorithm to port; CPU and Vulkan should share its one runtime definition, with independent tests pinned separately. No post-failure precision limit changes or generic fallback abstractions are planned.
