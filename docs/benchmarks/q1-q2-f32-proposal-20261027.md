# Q1_0 and Q2_0 exact-fixture F32 proposal

Status: user approved on 2026-10-27 after the strict failures and explicitly
required independent correctness proof before merging. The allowance is now
installed for qualification. This is an empirical acceptance amendment, not
a mathematical bound or a passed gate.
The [machine-readable scope](q1-q2-f32-proposal-20261027.json) pins each
variant, configuration, decoded-weight hash and packed-weight hash.

| Q2_0 split dense-untied | 0.000020000 | 0.000078201 | 0.000098201 |

The rule adds the existing margin to the largest independent HF F32
full-prompt versus cached-forward difference within the same family and
ordinary/split shape. Its inputs are the fixed five-seed dense, tied and MoE
reference sweep, not candidate error maxima. All 60 models and 300 comparisons
remain in the [reference evidence](q1-q2-f32-reference-sensitivity-20261027.json).
Canonical full-forward results reproduce the committed goldens exactly.
Dense models have no routing, split MoE uses all experts, and the ten ordinary
MoE models preserve their selected expert sets. This is not a routing-margin
robustness test. Two memory-guard stops and the resumed executions are retained.

Current main with independently decoded F32 weights reproduces Q1's CPU
ordinary untied failure exactly. For Q2 split dense-untied, all 13 batched
rows are bit-identical between packed Q2 and main F32, including the failed
endpoints. Main's decode also exceeds the old bound, though it differs from
packed decode. See the [matched control](q2-split-main-f32-control-20261027.json).

Q1's Vulkan packed and decoded-F32 paths differ. The packed path slightly
exceeds the old limit while the F32 storage path stays inside it. Independent
format/operator checks pass, but these controls do not prove every model
operation correct. The proposed wider margin could admit a small implementation
error. That risk is why this requires a policy decision and retains the
independent operator, NLL, released-file and depth checks.

Only the three listed fixture identities may use this logit
limit, and only with completed all-F32 matrix-path witnesses. It applies to
CPU and Vulkan, CLI and raw-capture consumers through the existing shared
test-bound owner. All other fixtures stay strict. NLL remains 1e-5, and no
runtime arithmetic, dtype, operator, released-file or long-context limit changes.
Original failures remain recorded. Approval permits affected qualification;
it does not qualify any untested path or permit merging without the other gates.

A cheap agent reviewed sweep independence and completeness and identified
