# `src/quant/low_bits.hpp` - Q1_0 and Q2_0 block decoding

This is the shared read-only CPU decoder owner for Q1_0 and Q2_0. Q1_0 blocks are 18 bytes: a little-endian binary16 scale and 16 packed sign bytes for 128 values; codes 0/1 map to `-d/+d`. Q2_0 is GGML type 42, also 18 bytes, with a binary16 scale and 16 bytes containing 64 low-to-high two-bit codes; codes 0, 1, 2 and 3 map to `-d`, signed zero, `d` and `2d`. Both retain the scale's sign and resulting signed zeros. CPU registry products use the generic row path; neither type has a quantize writer or specialized CPU dot.

The native `low-bits` check covers packed positions, every finite binary16 scale, unaligned blocks, zero-block calls, output guards and CPU products against independent field/double oracles. `tests/raw_blocks.py` independently checks the pure and NumPy spec decoders; `tests/roundtrip.py` sends raw Q1_0 and Q2_0 blocks through the CLI dequantizer and compares them bit for bit with that decoder. The Python `low-bits` component builds dense tied/untied and MoE fixtures from those raw blocks and consumes independent HF references. `tools/gen_baseline.py q1-0` and `q2-0` are separate reference selectors. The [Vulkan owner](backends-vulkan.md) describes the shared shader decoder and embedding, row and tile consumers. Q1 and Q2 qualification is complete; [STATUS](../STATUS.md) records their evidence and performance tradeoffs.
