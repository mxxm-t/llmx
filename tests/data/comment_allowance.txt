# The files whose comments the comment check (tests/docs_check.py, AGENTS.md, Dead code and stale docs) still finds walls in, and the reason each is not yet swept.
# One per line: file | blocks | digest | reason, where blocks is how many comment blocks of the file are walls and digest is a digest of their text.
# A file not listed holds none; a file whose count or whose walls' text differs from its line fails the check, and so does a line whose file holds none, so a wall is never added or replaced in a listed file.
# The change that sweeps a file removes its line; the digest is not edited to let a changed wall through.
